**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Guide overlay di tiap kelipatan 1080, toggle tampil/sembunyi jalan
- [ ] Guide tidak ikut ter-render saat export
- [ ] Scroll horizontal canvas jalan di Chrome Windows (Shift+wheel / drag background)
